## What it does

`main.ts` (Node 22, no network, fully deterministic) writes a single line to
`/output/entry.txt` — one small good thing that happened today, told warmly,
with a surprising turn and one concrete detail.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. Pass a path as the first
argument to write somewhere else instead, e.g. `node main.ts ./entry.txt`.
